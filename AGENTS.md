# Правило репозитория

Никогда не добавляй в Git и не отправляй на GitHub секреты, пароли, API-ключи, содержимое `.env`, приватные ключи и персональные данные учеников. В `.env.example` допускаются только явно фиктивные значения. Перед каждым коммитом и push проверяй список отслеживаемых и подготовленных файлов.
