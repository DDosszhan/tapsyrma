# IGCSE Data Representation chapter

These five lessons are original teaching material for the existing grade 9 course. The topic coverage follows sections 1.1–1.3 of the [Cambridge IGCSE Computer Science 0478 syllabus for 2026–2028](https://www.cambridgeinternational.org/Images/697167-2026-2028-syllabus.pdf). The [Cambridge endorsed coursebook listing](https://www.cambridgeinternational.org/programmes-and-qualifications/cambridge-igcse-computer-science-0478/published-resources/) was used to check the chapter scope and teaching approach.

Lesson text and SVG diagrams were written for Tapsyrma. No textbook pages, illustrations or exercises are reproduced. Run `python manage.py update_data_representation_lessons` to preview changes; add `--apply` to update the five lesson bodies. This command does not alter practice questions or student submissions.
