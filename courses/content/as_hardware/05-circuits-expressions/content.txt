## One rule, three representations

A circuit can be described using an everyday condition, a Boolean expression and a truth table. Cambridge AS students must be able to move between these representations, not merely name gates.

## Step 1: Turn a sentence into a Boolean expression

A warning lamp X should switch on if sensors A AND B are active, OR emergency switch C is active. Write X = (A AND B) OR C. The parentheses mean first evaluate A AND B, then combine the result with C using OR.

[diagram:as-circuit-chain]

## Step 2: Build the circuit

Draw separate wires labelled A and B into the two inputs of a standard AND gate. Label its output T. Connect T to one input of a standard OR gate; connect C directly to the other OR input. Label the OR output X. Show an actual wire from one gate's output to the next gate's input, rather than placing gate names in a list. If wires cross without joining, do not add a junction dot. Each wire carries either 0 or 1.

## Step 3: Construct the truth table

List all eight combinations of A, B and C from 000 to 111. Make a temporary column for T = A AND B. Then calculate X = T OR C. Intermediate columns reduce mistakes when a circuit has several gates.

[diagram:as-logic-conversions]

## Worked example 1: Trace one row

Suppose A = 1, B = 0 and C = 1. First, A AND B is 0. Then 0 OR 1 is 1. The warning light is on, so X = 1.

## Worked example 2: Build a different expression

A safety indicator is on only when both doors A and B are shut and the emergency stop C is not active. Use X = A AND B AND (NOT C). Draw C into a NOT gate, whose output is NOT C. Draw A and B into the first AND gate, then connect its output and NOT C to the two inputs of a second AND gate. Its output is X. A pair of connected two-input AND gates implements the three-way condition.

## Common mistakes

Do not treat a multiple-gate circuit as one single operation. Keep intermediate values. In Cambridge AS, AND, OR, NAND, NOR and XOR symbols have two inputs, so represent three-way AND using two connected gates. Do not ignore brackets when tracing expressions.

## Quick recap

Read the problem, define inputs, write the expression, draw the gates and verify with a complete truth table.

## Apply your knowledge

On paper, draw the standard gate symbols and labelled wires for X = (A AND B) OR C; compare your circuit with the diagram. Calculate X for A=0, B=1, C=0 and for A=1, B=1, C=0, then propose a physical system for this rule. In the text practice, describe which gate receives each input and where its output goes.
