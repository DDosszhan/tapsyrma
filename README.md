# Tapsyrma

Платформа для ретейков формативных и суммативных работ. Сейчас работают вход администратора, создание экзамена и проверка доступности приложения и базы. Генерация вопросов, персональные коды и сдача будут добавляться по [архитектуре](ARCHITECTURE.md).

## Локальный запуск

Нужен Docker с работающим Linux Engine. Локальный `.env` уже создан; если его нет, скопируйте `.env.example` в `.env` и замените `DJANGO_SECRET_KEY` и `POSTGRES_PASSWORD` длинными случайными значениями.

```sh
docker compose up --build -d
docker compose exec web python manage.py createsuperuser
```

Откройте `http://localhost/admin/` и войдите созданным администратором. `http://localhost/healthz/` проверяет также соединение с PostgreSQL.

## Создание экзамена

В разделе «Экзамены» укажите название, предмет, 9-й или 10-й класс, общее количество вопросов и баллов. В строках «Типы вопросов» добавьте MCQ с одним правильным ответом и/или открытые вопросы; удалите строку, чтобы исключить тип. Количество вопросов и баллы по строкам должны точно совпадать с итогами экзамена.

Силабус можно вставить текстом или загрузить TXT, PDF либо DOCX до 10 МБ. Из файла извлекается текст, а оригинал хранится отдельно и доступен только администратору. После сохранения проверьте текст: PDF-сканы без текстового слоя требуют ручного OCR или вставки текста. Пока созданный экзамен — заготовка без сгенерированных вопросов.

## Перед запуском на VPS

В `.env` установите `DJANGO_DEBUG=0`, `SITE_ADDRESS=ваш-домен`, `DJANGO_ALLOWED_HOSTS=ваш-домен` и `DJANGO_CSRF_TRUSTED_ORIGINS=https://ваш-домен`. Направьте DNS на VPS и откройте порты 80/443; Caddy получит HTTPS-сертификат. Не публикуйте порт PostgreSQL. Настройте внешние резервные копии базы до работы с реальными результатами.

`.env` и приватные ключи игнорируются Git и Docker. В репозиторий отправляйте только `.env.example` с фиктивными значениями. Перед `git push` проверяйте `git diff --cached --name-only` и `git ls-files`.
