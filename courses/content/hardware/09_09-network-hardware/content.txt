## Network Hardware: NICs, MAC Addresses, IP and Routers

### Learning goals

By the end of this lesson, you should be able to explain the roles of a NIC, MAC and IP addresses and a router, and recognise IPv4 and IPv6 formats.

### Why this matters

When you join the school Wi-Fi, your device needs both hardware and addresses to communicate. A network interface connects it, IP helps traffic reach networks, and a router sends packets toward their destination.

### Step 1: Network interface card

A NIC is the hardware interface that allows a device to connect to a network, either wired or wireless.

### Step 2: MAC address

A Media Access Control (MAC) address identifies a network interface at the link level. The syllabus describes it as assigned at manufacture and usually written in hexadecimal; a typical 48-bit MAC address has a manufacturer portion and a device-specific portion.

[diagram:network-path]

### Step 3: IP address

An Internet Protocol (IP) address identifies a device/interface for network communication and may be assigned statically or dynamically. IPv4 uses 32-bit addresses, commonly dotted decimal. IPv6 uses 128-bit addresses, commonly written in hexadecimal groups.

### Step 4: Router

A router forwards packets toward their destination between networks. A home/school router may also assign local IP addresses and provide access from a LAN to the internet.

### Step 5: Compare MAC with IP

For the exam, distinguish the generally hardware-associated MAC address from the network-assigned IP address. In real systems MAC randomisation and software-configurable addresses exist, but Cambridge focuses on the usual model.

[diagram:address-types]

### Worked example 1: School device connects

A laptop NIC joins the Wi-Fi network. The network allocates an IP address; the router can forward packets toward an external web server.

### Worked example 2: Identifying address formats

An address such as 192.168.1.20 is in dotted-decimal IPv4 format. An address such as 2001:db8::5 uses IPv6 hexadecimal notation. A MAC address is commonly six pairs of hexadecimal digits, such as 00:1A:2B:3C:4D:5E.

### Common mistakes

Tip: A MAC address identifies a network interface at the link level; an IP address supports network communication and routing.

Tip: IPv6 is usually written in hexadecimal groups separated by colons, not decimal dots.

Tip: A router forwards traffic between networks; wireless access is a separate function that may be built into the same device.

### Quick recap

NIC connects; MAC identifies the interface locally; IP provides network addressing; router forwards packets between networks.
