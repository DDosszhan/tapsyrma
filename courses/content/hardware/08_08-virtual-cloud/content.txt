## Virtual Memory and Cloud Storage

### Learning goals

By the end of this lesson, you should be able to explain paging and its effect on speed, describe where cloud files are stored, and compare cloud with local storage.

### Why this matters

Sometimes the programs open on a computer need more memory than the available RAM. At other times, people need files on several devices. Virtual memory and cloud storage solve different problems.

### Step 1: Virtual memory purpose

When available RAM is insufficient, an operating system can use an area of secondary storage to temporarily hold some memory pages.

### Step 2: Paging between RAM and storage

Pages of data are transferred between RAM and the virtual-memory area as needed. Accessing secondary storage is usually slower than RAM, so heavy paging reduces performance.

[diagram:paging]

### Step 3: Cloud storage meaning

Cloud storage stores data on physical servers accessible remotely through a network. It is not data floating without hardware.

### Step 4: Benefits of cloud storage

Cloud services can allow remote access, collaboration and off-site copies, depending on the service and configuration.

### Step 5: Limitations and choice

Cloud storage may need reliable internet access, introduce ongoing subscription costs, and create privacy/security considerations. Local storage can provide offline access and direct control but needs local backup and maintenance.

[diagram:cloud]

### Worked example 1: Too many applications

A computer with limited RAM runs several large programs. The OS moves less-used pages to secondary storage and brings them back as required. Switching between apps may become slower.

### Worked example 2: Group project

Two students edit the same project from different locations. A suitable cloud service can keep shared files accessible, but the students still need access permissions and connectivity.

### Common mistakes

Tip: Virtual memory uses secondary storage when RAM is insufficient; it does not add physical RAM.

Tip: Virtual memory supports memory management; cloud storage provides remotely accessible file storage.

Tip: Cloud files still reside on physical servers.

### Quick recap

Virtual memory = paging between RAM and secondary storage. Cloud storage = remotely accessible files stored on physical servers.
