# Tapsyrma

Платформа для ретейков формативных и суммативных работ. Работают создание экзамена, генерация вопросов через OpenAI, вход ученика по почте, общий или персональный код, сдача и проверка ответов. Общая схема — в [архитектуре](ARCHITECTURE.md).

## Локальный запуск

Нужен Docker с работающим Linux Engine. Локальный `.env` уже создан; если его нет, скопируйте `.env.example` в `.env` и замените `DJANGO_SECRET_KEY` и `POSTGRES_PASSWORD` длинными случайными значениями.

```sh
docker compose up --build -d
docker compose exec web python manage.py createsuperuser
```

Откройте `http://localhost/admin/` и войдите созданным администратором. На `/` всем виден список опубликованных тестов без вопросов и ключей. `http://localhost/login/` — вход ученика по почте и паролю; после входа он вводит общий или персональный код. `http://localhost/healthz/` проверяет также соединение с PostgreSQL. Установите `STUDENT_INITIAL_PASSWORD` только в приватном `.env`; ученики обязаны сменить его при первом входе. Для генерации и проверки открытых ответов добавьте свой `OPENAI_API_KEY` в локальный `.env`. `OPENAI_MODEL` по умолчанию — `gpt-4o-mini`; можно поменять на совместимую со Structured Outputs модель. Ключ никогда не передается браузеру.

## Создание экзамена

В разделе «Экзамены» укажите название, предмет, 9-й или 10-й класс, общее количество вопросов, баллов и длительность в минутах. Для существующих экзаменов после обновления указано 60 минут; при необходимости измените это значение до новых сдач. Новые экзамены по умолчанию автоматически распределяют вопросы: около 25% MCQ, остальные — открытые, с целыми баллами и суммой, указанной администратором. Если точные 25% несовместимы с общим числом вопросов и баллов, выбирается ближайший допустимый вариант. Для ручной настройки снимите галочку «Распределить типы и баллы автоматически» и заполните строки «Типы вопросов»; суммы должны точно совпадать с итогами экзамена. Старые экзамены сохраняют свою ручную структуру.

Силабус можно вставить текстом или загрузить TXT, PDF либо DOCX до 10 МБ. Из файла извлекается текст, а оригинал хранится отдельно и доступен только администратору. После сохранения проверьте текст: PDF-сканы без текстового слоя требуют ручного OCR или вставки текста. Баллы за каждый вопрос должны быть целыми.

После проверки силабуса и структуры опубликуйте экзамен. Он сразу появится в общем списке. Вопросы генерируются отдельно для каждого выданного кода; общий банк вариантов больше не нужен. Типы, количество и баллы одинаковы для всех, а формулировки различаются. В разделе «Сгенерированные вопросы» администратор может проверить вопросы и критерии готовых вариантов до урока. Равная фактическая сложность не гарантируется одним промптом, поэтому перед важным суммативом нужна проверка человеком.

В «Ученики» добавьте почту, имя и класс. Админка создаст учетную запись с временным паролем из `.env`. Кнопка «Импорт из Excel» принимает `.xlsx`: первый столбец `email`, второй необязательный `name`, класс выбирается на странице импорта; первая строка может быть заголовком. Без имени используется почта. Повторная загрузка пропускает уже существующие учетные записи. Ошибка в файле отменяет весь импорт. Суперпользователь может выбрать учеников и через меню действий сбросить их пароли к начальному значению из приватного `.env`; при следующем входе они обязаны их сменить. Действие «Удалить вход и обезличить историю» требует отдельного подтверждения: учетная запись, имя и почта удаляются, результаты остаются без имени. Система не отправляет пароли по почте: сообщите начальный пароль ученикам отдельно. Общий начальный пароль позволяет постороннему, знающему почту ученика, войти первым и сменить его; до выдачи реальных аккаунтов лучше заменить эту схему персональными временными паролями.

В «Общие коды» укажите срок выбора экзамена и сохраните. Случайный 8-символьный код появится **один раз** после сохранения; его можно дать всему классу. Ученик входит в свой аккаунт, вводит код и выбирает **один** опубликованный экзамен **своего класса**. Выбор закрепляется за учеником: повторный ввод этого кода возвращает к тому же экзамену. Для каждого ученика создается отдельный вариант; фоновый `generator` готовит вопросы после выбора, поэтому начало может занять несколько минут. После выбора остается минимум час на начало, даже если общий код истек раньше. Администратор может отключить или перевыпустить общий код; прежние сдачи и варианты сохраняются.

Личные коды тоже доступны. В «Коды на сдачу» выберите опубликованный экзамен, ученика и срок начала. Случайный код появится один раз после сохранения. Дождитесь статуса «Готов» до урока; при ошибке выберите действие «Повторить генерацию ошибочных вариантов». Код работает только после входа в учетную запись именно этого ученика. При потере кода используйте действие «Перевыпустить коды»: старый перестанет работать, уже начатая попытка сохранится. Ученик вводит код и начинает экзамен, когда вариант готов. Ответы сохраняются автоматически и при отправке. Повторный вход до отправки возвращает ту же работу. Время отсчитывается от нажатия «Начать экзамен», срок фиксируется для этой попытки. После его окончания сервер отправляет последние сохраненные ответы на проверку, даже если вкладка закрыта. Попытки, начатые до установки таймера, остаются без нового срока. После сдачи фоновый `worker` выставляет баллы: MCQ по сохраненному ключу, открытые ответы через ИИ по заранее сохраненным критериям. В «Сдачи» видны все результаты, а ошибочную проверку можно отправить повторно. Ученик видит свою историю на `/history/`, итог, баллы за каждый критерий и объяснения только после проверки.

Чтобы учитель мог выдавать коды и видеть работы, администратор создает ему учетную запись Django с `is_staff` и разрешениями на учеников, приглашения, общие коды и просмотр сдач. Создание экзаменов и просмотр сгенерированных вопросов доступны только суперпользователю.

Для 9 класса генерация ориентируется на Cambridge IGCSE, для 10 класса — на Cambridge International AS Level: командные слова, уместная глубина применения знаний и распределение целых баллов по шагам. Это оригинальные задания Tapsyrma, не официальные материалы Cambridge. ИИ может ошибаться в вопросах и оценивании: администратор проверяет готовые персональные варианты, учитель решает, какую оценку выставить в EduPage. Генерация тратит API-баланс на **каждого ученика, выбравшего экзамен**, даже если код у всех один.

## Проверка кода

```sh
docker compose exec web python manage.py test exams --settings=tapsyrma.test_settings
```

## Перед запуском на VPS

В `.env` установите `DJANGO_DEBUG=0`, `SITE_ADDRESS=ваш-домен`, `DJANGO_ALLOWED_HOSTS=ваш-домен` и `DJANGO_CSRF_TRUSTED_ORIGINS=https://ваш-домен`. Направьте DNS на VPS и откройте порты 80/443; Caddy получит HTTPS-сертификат. Не публикуйте порт PostgreSQL. Настройте внешние резервные копии базы до работы с реальными результатами.

На VPS таймер `ops/tapsyrma-backup.timer` ежедневно сохраняет PostgreSQL, приватные файлы и `.env` в `/var/backups/tapsyrma`, с хранением 14 дней. Каталог доступен только root; это локальная копия. Для защиты от потери VPS нужна отдельная копия вне сервера.

`.env` и приватные ключи игнорируются Git и Docker. В репозиторий отправляйте только `.env.example` с фиктивными значениями. Перед `git push` проверяйте `git diff --cached --name-only` и `git ls-files`.
