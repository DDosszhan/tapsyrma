Uploading replaces the current fixed questions in this draft. Review the imported questions and attach any required images before publishing.

Download the XLSX template. Each row is one question. Use open or mcq for kind, and ai or manual for grading_mode. For MCQ, fill four options and the correct option (1–4 or A–D). Criteria and model answer are optional for open questions; write each criterion on a separate line as 1: Description. Set requires_image to yes when an image must be attached after import.

TXT, DOCX and PDF also work when each question starts on its own line, for example Question 1 — Logic Gates [3 marks]. The text up to the next question heading is kept as the question. Put an optional [[MODEL ANSWER]] and [[CRITERIA]] section after the question text. A criteria section uses the same 1: Description lines. Scanned PDFs need a text layer or OCR. Lines such as Question type: File upload or manually marked response select teacher grading and are removed from student text; IMPORTANT: Insert supplied image ... is removed and requires you to attach the image in the question editor.
